How to read this prototype

All three demonstration indicators increase when performance improves. Attainment = actual ÷ target × 100. On track: ≥90%; watch: ≥70% and <90%; below target: <70%. These are illustrative thresholds, not rules attributed to Botswana’s M&E manual.

Percentage indicators use percentage-point values for actual and target. Counts and percentages retain their own units. No cross-indicator average is calculated. A filtered sector bar is the number of on-track observations divided by all visible observations in that sector.

The dataset is fixed and synthetic, not a live reporting feed. Reporting quarters are examples, not an adopted reporting calendar.

Before introducing research data

  • Verify indicator definitions, units, direction and reporting frequency against the National Performance Monitoring and Evaluation Manual.
  • Agree the NPC case boundary, data access and ethics requirements.
  • Validate coordinates and introduce approved, de-identified observations.
  • Evaluate usefulness and usability with the intended participants.

AI is not enabled. Any future assistance needs a defined task, human verification and separate secure hosting for credentials.

Map sources: OpenStreetMap contributors for the basemap; Leaflet for map interaction. The browser requests map tiles and library files from external providers. Town coordinates are approximate demonstration references.

Data handling: filters run in your browser. There is no login, database, analytics or server upload. CSV export contains only the filtered synthetic observations. Published site files are public.
